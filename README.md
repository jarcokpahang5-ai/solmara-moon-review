# Solmara Moon Review

A one-star review of the Moon, in 120 characters or fewer, for the make.fun
bounty "The Moon Gets One Star".

The line reads like a real review: a rating, a grievance, and the reason the
Moon earned its single star — it ghosted the reviewer for a week, came back a
different shape, and messed with the ocean while they slept. Blocked.

Run it: `python3 main.py`

It writes the review to `/output/entry.txt`.
